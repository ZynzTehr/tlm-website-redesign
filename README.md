# The Last Mile Website Redesign

A tailored redesign of The Last Mile Website focusing on symmetry, readable typography, and cohesive branding. Built with HTML, CSS, JavaScript, and Bootstrap, it features a responsive layout, custom aesthetics, interactive UI elements, and a unique resizing cursor Easter egg.

---

## Features

- **Personalized Design Aesthetics:** Utilizes semantic layouts balancing both symmetry and asymmetry. Images were selectively reconstructed.
- **Micro-Interactions & Easter Eggs:** Interactive UI cues like dynamic pointer events and a custom resizing cursor driven by JavaScript.
- **Brand Consistency:** Designed with core TLM colors, adjusting the palette to prioritize readability (excluding pure white to accommodate sensitive eyes).
- **Responsive Media Queries:** Removes explicit clutter on distinct viewport sizes and heavily leans on Bootstrap's grid abstractions for robust structuring.
- **Typography Matrix:** Pairs prestige Cursive fonts with clean Helvetica instances for an accessible and visually arresting structure.

---

## Technologies Used

- **JavaScript (ES6+)**
- **Bootstrap 5** (Navbar, Cards, Carousels, Modals, Buttons, Jumbotron)
- **HTML5**
- **CSS3**

## Design System

### Layout & Usability
The homepage acts as a graphical index utilizing standard Bootstrap Cards linked contextually to inform the user. The universal navigation bar incorporates distinct `:active` and `:focus` states supporting screen-readers and visual consistency.
